# Skill Claude: Trang giới thiệu & chính sách cho WordPress (Flatsome)

Tạo và đăng bộ 10 trang (giới thiệu, liên hệ, hướng dẫn mua hàng, đổi trả, bảo hành, vận chuyển, thanh toán, bảo mật, điều khoản, khiếu nại) lên web WordPress/Flatsome/WooCommerce theo luật Việt Nam. Thiết Kế Web DC · Bùi Viết Cường.

## Cài

```bash
git clone https://github.com/thietkewebdc/skill-wp-trang-chinh-sach.git ~/.claude/skills/wp-trang-chinh-sach-gioi-thieu
```

## Dùng

1. Trong thư mục làm việc: `cp ~/.claude/skills/wp-trang-chinh-sach-gioi-thieu/.env.example .env`, điền URL, tài khoản, Mật khẩu ứng dụng (SSH VPS/hosting là tùy chọn).
2. Mở Claude Code, gõ `/wp-trang-chinh-sach-gioi-thieu` (hoặc nói "tạo trang chính sách cho web").
3. Script chạy ở chế độ nháp; duyệt xong mới đăng.

Chi tiết quy trình, quyền truy cập và xử lý sự cố: xem [SKILL.md](SKILL.md).

> Nội dung chính sách là mẫu chuẩn hóa, không thay thế tư vấn pháp lý. Không commit file `.env`.
